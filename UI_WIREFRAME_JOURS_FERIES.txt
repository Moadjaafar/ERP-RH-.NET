ZONE 3: FORMULAIRE D'AJOUT/MODIFICATION
────────────────────────────────────────
• Background: Bleu clair (#e7f3ff)
• Border radius: 6px
• Padding: 20px
• Shadow: Ombre légère

Champs:
1. Nom (TextBox) - Largeur complète dans colonne 1
2. Type (DropDownList) - Colonne 2
   - Jour Férié (sélectionné par défaut)
   - Jour Spécial
3. Payé (DropDownList) - Colonne 3
   - Oui (Payé) - sélectionné par défaut
   - Non (Non Payé)
4. Date (DatePicker) - Colonne 1
5. Récurrent (RadioButtons) - Colonne 2
   - Oui / Non (Non sélectionné par défaut)
6. Type de Récurrence (DropDownList) - Colonne 3
   - Visible uniquement si "Récurrent = Oui"
   - Annuel (même date)
   - Mensuel
   - Personnalisé
7. Description (TextArea) - Largeur complète, 2 lignes

Boutons:
• [ Enregistrer ] - Vert, icône ✅
• [ Annuler ] - Gris, icône ❌

ZONE 4: FILTRES
────────────────
• Background: Gris clair (#f8f9fa)
• Border radius: 6px
• Padding: 20px

Sous-zones:
1. Navigation Année (Centre)
   - Bouton ◄ (Année précédente)
   - Bouton 2025 (Année courante, style primaire)
   - Bouton ► (Année suivante)
   - Groupés ensemble avec ombre

2. Filtre Type (Gauche)
   - DropDownList: Tous / Jours Fériés / Jours Spéciaux
   - Auto-postback activé

3. Filtre Statut (Droite)
   - DropDownList: Tous / Passés / À Venir / Aujourd'hui
   - Auto-postback activé

4. Légende (En bas)
   - 3 items avec carrés de couleur:
     🔴 Rouge = Jour Férié
     🟡 Jaune = Jour Spécial
     🟢 Vert = Récurrent

ZONE 5: LISTE (GRIDVIEW)
────────────────────────
• Table responsive
• Header sticky (reste en haut lors du scroll)
• Hover effect sur les lignes

Colonnes:
1. DATE
   - Ligne 1: Date formatée (01/01/25)
   - Ligne 2: Jour de la semaine (mercredi)
   - Font: Bold pour la date

2. NOM
   - Nom complet du jour férié
   - Font: Regular

3. TYPE
   - Badge coloré:
     🔴 "Jour Férié" (background rouge #dc3545)
     🟡 "Jour Spécial" (background jaune #ffc107)

4. PAYÉ
   - Badge:
     ✅ "Oui" (background vert)
     ⚠️ "Non" (background orange)

5. RÉCURRENT
   - Badge:
     🟢 "YEARLY" / "MONTHLY" (background info #17a2b8)
     ⚫ "Non" (background gris)

6. DESCRIPTION
   - Texte tronqué si trop long
   - Tooltip au survol

7. STATUT
   - Badge dynamique basé sur la date:
     🟢 "Aujourd'hui" (vert)
     ⚫ "Passé" (gris)
     🟡 "Dans X jour(s)" (jaune si < 7 jours)
     🔵 "À venir" (bleu si > 7 jours)

8. ACTIONS
   - Bouton ✏️ Modifier (bleu, icône crayon)
   - Bouton 🗑️ Supprimer (rouge, icône poubelle)
   - Alignement: Centre

Empty State:
• Icône: 📅 (grande, grise)
• Texte: "Aucun jour férié trouvé pour cette période"
• Sous-texte: "Utilisez le formulaire ci-dessus pour ajouter des jours fériés"

ZONE 6: JOURS PRÉDÉFINIS

  - Liste des jours inclus (petit texte gris)

                                    COMPORTEMENTS INTERACTIFS
═══════════════════════════════════════════════════════════════════════════════════════════════════

1. AJOUT D'UN JOUR FÉRIÉ
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Utilisateur remplit le formulaire                        │
   │ 2. Clic sur "Enregistrer"                                   │
   │ 3. Validation côté client                                   │
   │ 4. Postback vers serveur                                    │
   │ 5. Validation côté serveur                                  │
   │ 6. INSERT dans BD                                           │
   │ 7. Rafraîchissement statistiques                            │
   │ 8. Rafraîchissement GridView                                │
   │ 9. Message de succès (alert)                                │
   │ 10. Formulaire vidé                                         │
   └─────────────────────────────────────────────────────────────┘

2. MODIFICATION D'UN JOUR FÉRIÉ
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Clic sur icône ✏️ dans GridView                         │
   │ 2. Scroll automatique vers formulaire                       │
   │ 3. Formulaire pré-rempli avec données                       │
   │ 4. Titre change: "Modifier Jour Férié..."                   │
   │ 5. Bouton change: "Mettre à jour"                           │
   │ 6. Utilisateur modifie                                      │
   │ 7. Clic "Mettre à jour"                                     │
   │ 8. UPDATE dans BD                                           │
   │ 9. Rafraîchissements                                        │
   │ 10. Message de succès                                       │
   └─────────────────────────────────────────────────────────────┘

3. SUPPRESSION D'UN JOUR FÉRIÉ
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Clic sur icône 🗑️                                       │
   │ 2. Popup de confirmation JavaScript                         │
   │    "Êtes-vous sûr de vouloir supprimer ce jour férié?"     │
   │ 3. Si "OK": Postback                                        │
   │ 4. UPDATE is_deleted = 1 (soft delete)                      │
   │ 5. Rafraîchissements                                        │
   │ 6. Message de succès                                        │
   │ 7. Si "Annuler": Rien ne se passe                           │
   └─────────────────────────────────────────────────────────────┘

4. NAVIGATION PAR ANNÉE
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Clic sur ◄ ou ►                                          │
   │ 2. Session["SelectedYear"] mise à jour                      │
   │ 3. Postback                                                 │
   │ 4. Bouton central mis à jour (ex: "2024")                   │
   │ 5. Requête BD filtrée par nouvelle année                    │
   │ 6. Statistiques recalculées                                 │
   │ 7. GridView rafraîchi                                       │
   └─────────────────────────────────────────────────────────────┘

5. FILTRAGE
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Changement dans DropDownList (Type ou Statut)            │
   │ 2. AutoPostBack = true déclenche postback                   │
   │ 3. Requête BD modifiée avec clause WHERE                    │
   │ 4. GridView rafraîchi avec résultats filtrés                │
   └─────────────────────────────────────────────────────────────┘

6. AJOUT JOURS PRÉDÉFINIS
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Clic "Ajouter Jours Fériés Officiels"                    │
   │ 2. Loop sur 9 jours fériés fixes                            │
   │ 3. Pour chaque jour:                                        │
   │    - Vérifier si existe déjà                                │
   │    - Si non: INSERT                                         │
   │    - Incrémenter compteur                                   │
   │ 4. Message: "X jour(s) férié(s) ajouté(s)"                  │
   │    ou "Déjà présents"                                       │
   │ 5. Rafraîchissements                                        │
   └─────────────────────────────────────────────────────────────┘

7. GESTION RÉCURRENCE
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. Clic sur radio "Récurrent: Oui"                          │
   │ 2. JavaScript affiche div "Type de Récurrence"              │
   │ 3. DropDownList devient visible                             │
   │ 4. Si "Non": div masquée                                    │
   └─────────────────────────────────────────────────────────────┘
